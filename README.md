# dhimantAI desktop downloads

Official staging preview installers from **Optficial Labs Pvt Ltd**.

- [Download releases](https://github.com/ssuda/dhimantai-downloads/releases)
- [dhimantAI Skilling and course catalog](https://dhimant.ai/upskill/)

Choose the operating system and processor matching your computer. Linux packages use `.deb` or `.tar.gz`; Mac packages use `.dmg`; Windows packages use `.exe`. Each release includes SHA-256 checksums.

These are evaluation previews connected to staging. Windows previews are unsigned; Mac previews use ad-hoc signing without notarization. Updates are installed manually. See each release for its available platforms and validation status.

The desktop includes Course Catalog, Instructor, Study, Doubt Solver and Practice. It starts with a light theme and learning navigation. Copilot remains optional and is permitted only in courses explicitly teaching AI-assisted coding.

This repository hosts release downloads. Third-party license and copyright notices are included with the application.
